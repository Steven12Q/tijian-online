# 题笺 Online Cloud v1.2.1

修复 v1.2 从旧数据库升级时，`chapter` 字段尚未创建就提前创建索引导致 Render 启动失败的问题。

功能与 v1.2 相同：按章节、按试卷双重分类；MathJax；题目/解析配图；管理员与教师；共享题库与组卷。


## v1.3 新增：批量导入试卷
教师和管理员可点击顶部“批量导入”，上传 JSON 题库包。支持一次最多 500 题，可选择跳过或覆盖相同 ID。示例文件：`海淀期中_批量导入测试.json`。


## v1.3.7
新增可视化图片排版设置：编辑题目时可直接调整位置、宽度、最大宽度、多图列数、间距、打印宽度，并实时预览。


## v1.3.9
- 选择题选项自动四列铺满；长选项自动两列（A/B 一行，C/D 一行）。
- 组卷改为“导出学生版 PDF / 导出教师版 PDF”两个入口；教师版附答案解析。


## v1.3.10
- 修复右侧配图题：仅题干与图片并排，选项恢复到下方全宽区域。
- 选择题按视觉宽度自动布局：短选项四列；较长选项自动 A/B、C/D 两列。

## v1.3.11
- 选择题改为全局三级自适应：短选项四列；中等选项两列 A/B、C/D；长选项单列。
- `\rule{...}{...}` 填空线由网页直接渲染为实线，学生版/教师版 PDF 同步生效。

## v1.3.12
- “按试卷”页面选择某一来源试卷后，可一键导出整卷学生版 PDF 或教师版 PDF。
- 整卷自动按原试卷题号排序，不需要逐题加入。
- 增加“整卷加入组卷”，方便整卷导入后再做删题、换题、调整顺序。


## v1.4
- “专题 / 计划”命名统一为“章 / 节”，建立 11 章 51 节的固定高中数学目录。
- “按章/节”页面改为两级目录：先选章，再选节。
- 录题界面增加“章”“节”下拉框，并保留“知识点/标签”。
- 旧题和旧 JSON 导入时，会结合标题、知识点、题干、解析与标签自动归入新的章、节。
- “按试卷”侧栏增加“搜索试卷”输入框，试卷多时可以按名称快速定位。
- 原有按试卷、原题号排序、整卷导出、组卷、图片排版、MathJax 功能保持不变。
