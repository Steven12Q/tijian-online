# 题笺 Online Cloud v1.2.1

修复 v1.2 从旧数据库升级时，`chapter` 字段尚未创建就提前创建索引导致 Render 启动失败的问题。

功能与 v1.2 相同：按章节、按试卷双重分类；MathJax；题目/解析配图；管理员与教师；共享题库与组卷。


## v1.3 新增：批量导入试卷
教师和管理员可点击顶部“批量导入”，上传 JSON 题库包。支持一次最多 500 题，可选择跳过或覆盖相同 ID。示例文件：`海淀期中_批量导入测试.json`。


## v1.3.7
新增可视化图片排版设置：编辑题目时可直接调整位置、宽度、最大宽度、多图列数、间距、打印宽度，并实时预览。


## v1.3.9
- 选择题选项自动四列铺满；长选项自动两列（A/B 一行，C/D 一行）。
- 组卷改为“导出学生版 PDF / 导出教师版 PDF”两个入口；教师版附答案解析。


## v1.3.10
- 修复右侧配图题：仅题干与图片并排，选项恢复到下方全宽区域。
- 选择题按视觉宽度自动布局：短选项四列；较长选项自动 A/B、C/D 两列。
